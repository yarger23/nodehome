## Протокол публикации

- Добавить уникальные исходные изображения в assets/images/ по точным slug, проверить WebP/AVIF, размер >=1200×800, 25 KB+, соответствие теме.
- Проверить внутренние ссылки в четырёх статьях; провести тематическую и фактологическую сверку, особенно два материала о плинтусах.
- В ОДНОМ коммите изменить status на published и вписать slug/id в единственный соответствующий список content/categories.json.
- Дождаться успешной сборки Github Actions (preflight-new-articles.mjs, build.mjs, verify-built), проверить site/article/.../index.html и sitemap.
- После успешной генерации перенести обновлённый site/ из main на VPS: cd /opt/nodehome-source && git pull --ff-only origin main && cp -a site/. /var/www/nodehome/
- Проверить страницы в браузере после выкладки. Без фактической проверки VPS не объявлять материалы размещёнными на живом сайте.
