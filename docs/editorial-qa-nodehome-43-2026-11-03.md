## Требования для оставшихся обложек

Изображение уникальное, фотореалистичное, без текста и водяных знаков, не повторяет другие изображения Nodehome. Формат WebP/AVIF, размеры не менее 1200×800 настоящих пикселей, файл не меньше 25 КБ и по возможности достаточно хорошо сжат. Точное имя файла: `<slug>-hero.webp`.

## Контроль перед публикацией

1. Загрузить четыре уникальных изображения в `assets/images/`.
2. Заменить `status=draft` на `published` и зарегистрировать ID каждой статьи ровно один раз в соответствующей категории `content/categories.json`.
3. Запустить `node scripts/qa-nodehome-43.mjs`, `node scripts/preflight-new-articles.mjs` и `node scripts/build.mjs`.
4. Подтвердить собранные HTML, canonical, sitemap и реальные размеры изображений.
5. После успешных тестов передать изменения в `main`, затем отдельно обновить файлы на VPS; наличие кода в GitHub не доказывает выкладку на сервер.

**Ограничение проверки уникальности:** отсутствие точных внутренних дублей и разный поисковый смысл близких материалов не заменяют внешний проверенный антиплагиат. Гарантировать отсутствие совпадений со всем интернетом без такой проверки нельзя.
