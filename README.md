# Nodehome

Публичный сайт о строительстве и ремонте. Страницы заранее собираются в HTML, поэтому каталог и статьи доступны по обычным адресам и не зависят от клиентского роутера.

## Структура

- **content/** — структурированные данные сайта, категорий и статей.
- **assets/** — исходные CSS, JavaScript и локальные изображения.
- **scripts/build.mjs** — генератор статических страниц без сторонних зависимостей.
- **site/** — готовый сайт для размещения в корне веб-сервера.
- **docs/architecture.md** — устройство проекта и основа для будущей админ-панели.

## Сборка и проверка

Для генерации страниц нужна Node.js 18 или новее. Установка пакетов не требуется.

    node --check scripts/build.mjs
    node --check assets/site.js
    node scripts/build.mjs

Генератор создаёт отдельные HTML-страницы для направлений (/construction/), тематических групп и каждой подтемы. Общий каталог остаётся по адресу /catalog/, а существующие страницы категорий (/catalog/land/, /catalog/foundation/, /catalog/walls/, /catalog/floors/) и статей сохраняют свои URL. Старые адреса направлений и групп ведут на новые страницы.

## Публикация на VPS

После обновления main перенесите готовые файлы в корень сайта:

    cd /opt/nodehome-source
    git pull --ff-only origin main
    cp -a site/. /var/www/nodehome/

Nginx должен обслуживать каталоги с index.html и файлы assets/, robots.txt и sitemap.xml. Для этой публикации менять сертификат или перезапускать Nginx не требуется.

## Контент

Изменяйте файлы в content/, затем запускайте генератор и сохраняйте обновлённую папку site/. Стабильные slug формируют адреса статей и категорий. Перед переименованием slug нужно предусмотреть постоянный редирект со старого URL.
