# Nodehome — строительный портал «СЛОЙ»

Информационный портал о строительстве, ремонте, материалах и строительных калькуляторах.

## Текущая версия

В репозитории размещён **интерактивный HTML-прототип**. Он полностью автономный: вся вёрстка, стили, SVG-иллюстрации и JavaScript находятся в файле `index.html`. Устанавливать зависимости для просмотра не нужно.

**Важное ограничение:** разделы и статьи в прототипе переключаются внутри одного HTML-документа с помощью hash-навигации. Это ещё не полноценный SEO-сайт: для индексации тысяч материалов понадобятся отдельные URL, серверная генерация страниц и CMS.

## Как включить публикацию через GitHub Pages

1. Откройте **Settings → Pages** в настройках репозитория.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Установите ветку `main`, каталог `/(root)` и нажмите **Save**.
4. После завершения публикации прототип будет доступен по адресу [https://yarger23.github.io/nodehome/](https://yarger23.github.io/nodehome/).

GitHub Pages используется только для демонстрации текущего статического прототипа. Production-версия с CMS, аналитикой и тысячами SEO-страниц потребует отдельной архитектуры и инфраструктуры.

## Структура

- `index.html` — главная, каталог, статья и калькуляторы в одном автономном демо-файле.
- `README.md` — документация проекта.
